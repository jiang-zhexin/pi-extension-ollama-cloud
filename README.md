# Pi Ollama Cloud

Yet Another Ollama Cloud Extension for the [Pi](https://pi.dev) coding agent.

Include **ollama cloud provider** and **web search/fetch** tools. Nothing more.

Most extensions I've tried seem to be compensating for something. Config that fights pi's philosophy, feature lists that look like a spaceship's dashboard, and UIs that assume you wanted a personal assistant.

This one does less. On purpose.

## Features

- **Boring code.** A single file, ~200 lines. Auditing it takes less time than reading this README.
- **Boring config.** No config files, no opinionated defaults. Set one API key, get on with your life.
- **Invisible.** No new commands, no UI surface, no surprises. If you didn't know it was installed, you'd never notice.

## Quick Start

### Installation

```bash
pi install git:github.com/jiang-zhexin/pi-extension-ollama-cloud
```

### Login

```plaintxt
/login ollama-cloud
```

Now the ollama cloud models and web search/fetch tools are good to go.
